# HICM V2025 Assessment Source Files

This repository contains the source spreadsheets that define the HICM V2025 assessment content, scoring structure, and reporting outputs. Use the list below when mapping the assessment into a data-entry system.

## A_ส่วนที่ 1 บทนำและหลักการ.xlsx
- Introductory content for the assessment (objectives, framework, and HICM concept).
- Use this file as the textual introduction for the assessment portal and documentation.

## B_ส่วนที่ 2 โครงสร้างและระบบคะแนน.xlsx
- Defines the four pillars, their titles, the number of indicators, and weightings.
- Reference this file for pillar-level metadata and overall scoring weights.

## C_Pillar 1 Health Promotion (H1) - การส่งเสริมสุขภาพ.xlsx
- Pillar 1 assessment details and indicator-level criteria.
- Column layout includes: **ตัวชี้วัด** (indicator), **เกณฑ์** (criterion), **คำอธิบายตัวชี้วัด** (description), **เกณฑ์การประเมิน** (evaluation criteria), and scoring areas for self-assessment and committee review.

## D_Pillar 2 Industrial Safety & Environment (I2).xlsx
- Pillar 2 assessment details and indicator-level criteria.
- Structure mirrors Pillar 1 with indicator metadata, evaluation criteria, and scoring fields.

## E_Pillar 3 Community Engagement (C3).xlsx
- Pillar 3 assessment details and indicator-level criteria.
- Structure mirrors Pillar 1 with indicator metadata, evaluation criteria, and scoring fields.

## F_Pillar 4 Management & Sustainability (M4) .xlsx
- Pillar 4 assessment details and indicator-level criteria.
- Structure mirrors Pillar 1 with indicator metadata, evaluation criteria, and scoring fields.

## G_สรุปผลการประเมิน HICM V2025.xlsx
- Summarizes pillar-level scores and totals for the overall assessment.
- Use this sheet as a reference for the final scoring report.

## H_แบบฟอร์มการประเมินและสรุปผล.xlsx
- Provides the evaluation form and summary section for collecting and reporting the final scores.
- Use this as the template for the final assessment reporting workflow.

## DATA.xlsx
- Consolidated data draft for the full HICM V2025 assessment.
- Can be used as a staging source when building the final data-entry dataset.
